# 水下考古潜水记录

直接打开`index.html`使用。点击平面图添加标记，支持筛选、编辑、删除、时间线和导出JSON。

## 出水交接

- 在地图上选中标记后，侧栏登记交接单：潜次、袋号、保存措施、接手人、登记人；每个标记只挂一张未结束单。
- 袋号已被占用、资料空白或潜次与标记不符的交接单，留在"异常待处理"，补正后自动重判。
- 补录照片或更正类型后，该标记的旧交接单自动失效，按原资料抄出新单并按新资料重判（保留原登记时间，袋号占用顺序不变）。
- 待交接单在交接看板填写复核人后入库，复核人不能同登记人；已入库单仍占用袋号。
- 交接看板按潜次查看待交接、异常待处理和已入库；类型筛选与潜次筛选决定列表与导出内容。

## 文件结构

- `js/map.js` 地图：沉船平面图与标记渲染
- `js/judge.js` 判定：交接单校验、重判、失效与入库复核规则
- `js/archive.js` 存档：localStorage 持久化与导出
- `js/main.js` 页面装配与交互
